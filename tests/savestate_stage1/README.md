# Stage 1 real-core savestate roundtrip

This test runs the repository's SNES CPU, PPU, SMP/SPC700, DSP, WRAM controller,
LoROM/HiROM mapper, standard `snes_rom_client`, `main.v`, `boot1_rom`, and MiSTer
savestate engine. The original 65816 fixture initializes a checkpoint and uploads
an original SPC700 program using the normal IPL handshake. Controller input then
causes the running CPUs to change WRAM, VRAM, palette, ARAM and DSP registers. The
actual helper serializes state into a toggle-handshake memory device, and the
actual restore routine must reconstruct it and resume the saved CPU execution.

No test code writes a replacement snapshot or directly restores core registers.
The byte arrays and CPU checkpoints are independent postconditions on the actual
RTL/helper transaction stream.

## Scope and limitations

- Standard SDRAM transaction-facing cartridge path, with a behavioral memory
  responder that preserves owner, tag and epoch and varies response latency
- Actual standard helper ROM interception/response in `main.v`
- Actual engine's DDR request/ack interface, with behavioral state storage
- Behavioral external WRAM, VRAM, ARAM, SRAM and FPGA RAM primitives
- Actual P65 A/X/Y/direct-page/data-bank register checks, palette and DSP volume
  checks, RAM equality, and a new native-NMI heartbeat after restore
- Optional DSP audio is deliberately muted; nonzero DSP volume registers and
  ARAM content are meaningful audio-state checks, not audible-output evidence
- All enhancement chips and MSU disabled; Sleep is outside this test

This is not APF command/controller, PSRAM pin, clock-domain crossing, Quartus fit,
Pocket hardware, commercial-game compatibility, audible-output, or full rendering
qualification. Those layers need their own evidence. It must not be described as
end-to-end Pocket savestate qualification.

## Run

Use installed GHDL, Verilator, Python and a C++ compiler. The runner never installs
or downloads software. With those tools on PATH:

    python3 tests/savestate_stage1/run.py --case all

Options: `--build-only`, `--skip-build`, `--out DIR`, and `--case` with `lorom`,
`hirom`, `missing-helper`, `stale-word`, or `failed-restore`.

The required negative controls remove helper contents, corrupt a real serialized
WRAM word, and withhold restore service. Each must fail with its specific oracle
signature, not an unrelated compilation error. `summary.json` records case
outcomes, source hashes, boundaries and limitations. State bytes are dumped from
actual engine writes, never generated by the expected-memory oracle.

## Simulation-only normalization

`prepare.py` records an explicit adaptation needed by the available mixed-language
flow. Production source is never edited by this test:

1. GHDL translates actual VHDL to Verilog with standard memory generics selected
2. Vendor FPGA RAM primitives are modeled with registered input addresses,
   unregistered outputs, zero initialization and same-port write-through
3. Instance labels with case-folded generated-net collisions are renamed only
4. The DSP mixed combinational/clocked process's local `LR` variable is split into
   identically assigned combinational and clocked names, matching the existing
   `tests/aram_timing/run.py` accommodation
5. Game Genie is disabled and held reset; its inactive outputs are tied off
6. The DSPn entity is analyzed for an inactive generate branch and must never
   elaborate; the no-chip mapper itself is actual RTL
7. Verilog port-name case is matched to production mixed-language instance ports,
   and translated mapper-private modules receive a namespace prefix

See `FIXTURE.md` for exact ROM markers and generated fixture specifications. Test
results are not implied by the presence of this harness: consult the latest
`summary.json` and logs.

## Oracle coverage details

The meaningful changed-state regions are 1,024 WRAM bytes, 256 VRAM bytes, 64
ARAM bytes, CGRAM entry zero, P65 A/X/Y, and both DSP master-volume registers.
After restoring, a second controller-triggered phase change requires fresh CPU
and SPC700 execution. A reset/init-entry guard rejects rebuilding phase A from
reset, and an exact saved heartbeat of at least three distinguishes its history.
The expected fixture patterns are calculated independently in the bench before
saving, rather than accepting arbitrary initial values as the oracle.

The test also compares 130,942 WRAM bytes, all 65,536 VRAM and 65,536 ARAM bytes,
and 2,048 SRAM bytes at the restore boundary. The 128-byte active-stack region is
excluded from WRAM equality; two heartbeat bytes are checked separately against
the exact saved value. Regions outside the mutated sentinels, SRAM, direct-page,
and data-bank checks are preservation/invariant checks, not proof that every
such byte/register was independently changed and restored. Video evidence is
PPU/VRAM/palette state, not rendered-frame comparison. Audio evidence is
SPC700/ARAM/DSP state and resumed SPC execution, not audible sample fidelity.

The helper model loads bytes decoded from the production `boot1.mif`. The runner
requires all 2,048 words and checks exact equality to the padded pinned helper
ROM; both files are hashed. Every modeled cartridge request is bounded by its
selected ROM mask, and every state-memory request must use slot zero, so truncated
array indices cannot hide an invalid upper address or slot.

A completed run binds the source dependency graph, normalized VHDL, translated
Verilog, direct compiled-source snapshots, simulator versions, binary, original
fixtures and actual serialized state dumps. `--skip-build` rejects source,
binary or compiled-snapshot drift. Unused APF/storage files are deliberately
outside this main-level dependency graph and need their separate tests.
